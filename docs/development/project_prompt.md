# Project Origin Prompt

This server was built from the following prompt:

> Create a cloud MCP server to make the following Paris open datasets accessible to AI assistants for transport planning and journey flow analysis:
>
> - **Real-time availability**: https://opendata.paris.fr/explore/dataset/velib-disponibilite-en-temps-reel/
> - **Station locations**: https://opendata.paris.fr/explore/dataset/velib-emplacement-des-stations/
>
> Requirements: Rust, TDD, Scaleway Container Serverless deployment, GitHub Actions CI/CD.

See [`CLAUDE.md`](../../CLAUDE.md) for current architecture and development guidelines.
